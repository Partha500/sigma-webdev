## 🛠️ How to Run

Most files are plain HTML/CSS/JS — just open in your browser:

```bash
# Open any HTML file directly
start HTML/portfolio/portfolio.html

# Or use Live Server in VS Code for best experience
```

For JavaScript mini-projects (Todo App, Guessing Game), open the `index.html` in a browser and interact via the browser's prompt/console.
